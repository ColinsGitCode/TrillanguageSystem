# CA-I1 学习卡片交互补齐验收报告

> 日期：2026-07-27
> 环境：本地 Docker Compose `three_lans_system`
> 结论：**PASS**

## 1. 用通俗的话说明发生了什么

学习卡片里选中文字后，原来主要只能标红或生成新卡。CA-I1 把这块补成了完整的
桌面学习工具条：

- 可以用红、黄、绿、蓝四种颜色做标记；
- 点击已经标记的文字，可以改颜色或取消标记；
- 可以复制选中的文字；
- 可以先确认语言和知识类型，再查询知识点；
- 用键盘扩展文字选区时，工具条也会自动出现并获得焦点。

这些操作都覆盖在原卡片上，没有修改 Markdown 正文，也没有复制一份新的卡片
内容。

## 2. 数据和系统边界

CA-I1 没有新增数据库表、migration 或后端 route：

- 新建、改色和取消标记继续使用 `card_annotations`；
- 取消标记是软删除，历史数据不会被物理抹掉；
- 复制只写浏览器剪贴板；
- 知识点查询复用 `/api/kg/lookups`，用户确认后才产生 append-only lookup；
- KG lookup 不直接修改 FSRS、学习队列或 Review Event；
- 卡片 Markdown、教材官方原文和学习调度数据均未修改。

纯汉字选区无法可靠判断是中文还是日语，因此页面不会自行猜测，必须由用户明确
选择 English 或日本語后才能查询。

## 5. 本阶段没有做什么

- 没有做移动端页面或移动端手势；
- 没有增加任意选区 TTS；
- 没有增加长批注编辑器；

- 没有 DROP 冻结的 `card_highlights`。

因此 CA-I1 可以作为桌面交互完成基线。后续若开发“朗读选区”，应单独定义 TTS
输入、语言确认、音频缓存和播放互斥规则，不应把它塞进注解表。

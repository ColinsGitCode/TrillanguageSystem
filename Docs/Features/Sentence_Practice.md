# 练一句

个人工作区的小型表达练习。Cards Factory 首页的「今天练一句」从已有三语卡挑题；三语卡阅读页的「练一句」限定当前卡。日语和英语可分别练习，不引入教材或复习记录作为先决条件。

- 中文题目先发到浏览器，参考答案留在服务端。优先取目标语言的卡片例句及随附中文翻译；同一表达的换场景优先用另一条例句，用完后才请求 DeepSeek 拟新场景。
- 用户提交后先保存原始作答，再请求一条关键反馈。反馈失败可重试同一答案，不能覆盖原作答。反馈不包含分数或通过状态。
- 「能独立表达」「还要练」和「我不同意」由用户决定。最近 30 次已提交作答可以作为换场景再练的入口。
- 迁移 017 只新增 sentence_practice_attempts 和其索引。练习不读写复习排程、复习事件、队列或卡片正文。未提交的题目不进历史记录。
- 练习 API 仅在个人工作区可用。作答时传给 DeepSeek 的只有本题场景、目标、参考例句与提交文本，不发送练习历史或其他卡片。

验证：tests/unit/sentencePractice.test.js 和 tests/e2e/sentence-practice.spec.js。端到端测试使用固定反馈，不调用线上模型。

语法说明 · 答案面

有礼貌地请求别人做某事;比「〜てください」更客气,相应变形(〜ていただけないでしょうか)可表达更多敬意。

動詞て形 + いただけませんか

例句 · 共同证明同一语法点

能请您把资料发给我吗?

2. もう一度いちど説明せつめいしていただけませんか。
能请您再说明一次吗?

3. 少々しょうしょうお待まちいただけませんか。
能请您稍等一下吗?
